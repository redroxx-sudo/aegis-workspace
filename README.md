# AEGIS

AEGIS is an independent assurance-plane concept for consequential AI-enabled systems. It is intended to help organizations evaluate proposed machine actions against explicit evidence, policy, authority, safety, and provenance requirements before execution.

## Public repository boundary

This repository is a public positioning and evaluation surface only. It intentionally contains no AEGIS implementation, six-primitives runtime, deployment configuration, proof artifacts, retained evidence, ownership records, internal security material, or confidential IP.

The six-primitives implementation scope is frozen and remains outside this repository. Nothing in this README should be read as a technical disclosure, product certification, security assurance, performance commitment, or statement that a particular control has been independently validated.

## What is included

- High-level product positioning
- Public-facing boundary and evaluation context

## What is not included

- Source code or executable implementation
- Cryptographic keys, credentials, or operational configuration
- Test vectors, proof packages, retained evidence, or audit records
- Ownership, inventorship, filing, or chain-of-title records
- Confidential architecture, implementation details, or buyer diligence material

## Evaluation

Public material is deliberately limited. Qualified parties may request an appropriate diligence pathway through the project owner. Any restricted material is shared separately and only under suitable terms.
